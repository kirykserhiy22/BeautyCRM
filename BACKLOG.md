## 5. Функції

- [x] **Кнопка «показати пароль»** (око) на вході й реєстрації (11.11.2026).
- [x] **Гід по додатку** (11.11.2026): 6 сторіс один раз після реєстрації, повторно — Налаштування → «Як користуватися». Картинки намальовані кодом (`BeautyCRM/OnboardingView.swift`).
- [x] **Нагадування для майстра** (13.11.2026, `BeautyCRM/Reminders.swift`) про майбутній запис (наприклад, за годину) — як нагадування в Календарі iPhone.
  Технічно: локальні сповіщення iOS, працюють і без інтернету. Налаштування «за скільки нагадувати» — у Settings.
  - Плюс сповіщення **«Завершіть запис»**: якщо час запису минув, а він не завершений і не скасований.
    Тап по сповіщенню відкриває цей запис. Сповіщення переплановуються при створенні, перенесенні, завершенні й скасуванні.
  - Дозвіл на сповіщення питати не при першому запуску, а коли майстер уперше створює запис (так частіше погоджуються).
- [ ] **Нагадування клієнту одним тапом** (пріоритет: найшвидша перевага над конкурентами, сервер не потрібен).
  - У картці запису кнопка «Нагадати клієнту» → вибір месенджера: Telegram, Viber, WhatsApp, SMS.
    Відкривається месенджер із готовим текстом; майстер лише натискає «Надіслати».
  - Текст збирається з шаблону: ім'я клієнта, дата, час, послуги (і, за бажанням, ціна) беруться із запису,
    адреса й підпис — із налаштувань майстра.
  - Settings → «Нагадування клієнтам»: поле адреси, редагування тексту шаблону з підстановками
    (`{ім'я}`, `{дата}`, `{час}`, `{послуги}`, `{адреса}`), попередній перегляд готового повідомлення.
  - Шаблон за замовчуванням — мовою додатку (5 мов). Дата й час — у форматі мови майстра.
  - Якщо в клієнта вказано Telegram-нік або телефон, відкривати чат саме з ним; якщо ні — меню «Поділитися».
  - Позначка в записі «Нагадування надіслано» (дата), щоб майстер бачив, кому вже нагадав.
  - Технічно: адреса й шаблон — поля в `UserProfile` (синхронізуються з сервером згодом);
    відкриття через URL-схеми месенджерів / `ShareLink`; Telegram/Viber/WhatsApp додати в `LSApplicationQueriesSchemes`.
- [ ] **Порівняння фото «до/після» поруч** — коли стане видно, що майстри користуються позначками.
- [ ] **Settings:** додати потрібні параметри (план підписки — див. розділ 2, нагадування — див. вище).

## 6. За запитом користувачів

Ці функції не плануються. Беремо в роботу лише тоді, коли реальні майстри про них попросять.

- [ ] **Запізнення клієнтів** («У кріслі», «Запізнюється», статистика в картці клієнта). Якщо знадобиться — найпростіший варіант:
  одна позначка «Запізнився» лише коли це сталося, без дій при звичайному візиті; у картці клієнта рядок «Запізнення: 3 із 12»;
  позначка біля імені лише якщо це повторюється. Спершу з'ясувати, що майстер робитиме інакше, знаючи про запізнення.
- [ ] **VIP-клієнти:** позначка важливих клієнтів. Заготовку прибрано (#45), щоб не перевантажувати додаток.
